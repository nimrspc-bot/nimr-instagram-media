# قوالب محتوى إنستغرام – نمر العالمية

- `build_slides.py`: كاروسيل 1080×1350 (HTML → Chrome headless → JPEG). مثال: مصطلح الأسبوع 01.
- `reel01.py`: ريلز 1080×1920 (مشاهد HTML → ffmpeg، مع أصوات مولّدة صناعياً فقط، بدون موسيقى محمية).
- `assets/`: الشعار (ملوّن وأبيض)، أيقونة القفل، نقوش النجمة الثمانية.
- الخطوط: `npm i @fontsource/cairo @fontsource/montserrat` ثم عدّل مسار FONTS في السكربت.
- المسارات داخل السكربتات تشير إلى /home/claude/... ؛ عدّلها حسب مكان النسخ.
